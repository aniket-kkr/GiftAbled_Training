Library Management System

A full-featured command-line multi-library catalog and inventory manager built using Python 3, object-oriented design, and robust CSV persistence.

Developed by Aniket Kumar • GiftAbled Training Program

📌 Project Overview

The Library Management System is a Python-based console application designed to help librarians and users manage multiple library branches, track books across different libraries, perform fast indexed searches, and ensure safe data persistence across system restarts without external database dependencies.

📚
Multiple Libraries
Organize books into distinct branches (e.g. City Library, Central College Library) with isolated tracking.
🔍
Multi-Field Search
Case-insensitive substring search across Book Title, Author Name, and unique ISBN identifiers.
💾
CSV Persistence
Automatic saving and reading from data/libraries.csv and data/books.csv with zero data loss.

🏗️ Project Architecture

The project follows modular software design principles, separating user interaction, business logic, and persistent storage layers.

Library/
├── main.py                # User Interface: Interactive 8-option CLI menu loop
├── library_manager.py     # Business Logic: LibraryManager class managing records & validation
├── csv_storage.py         # Data Layer: CSV read/write serialization helpers
├── data/                  # Persistent Storage Directory (auto-created on startup)
│   ├── libraries.csv      # Library records (ID, Name)
│   └── books.csv          # Books catalog (ID, Title, Author, ISBN, Year, Library ID)
└── tests/
    └── test_library.py    # Automated test suite using Python unittest

📊 Data Model & Storage Specifications

Data persistence is implemented using Python's native csv module with explicit headers and atomic write handling.

1. data/libraries.csv

Field Name Type Constraint Description
library_id String Primary Key, Unique, Non-empty Unique identifier for the library branch (e.g., L1, L2).
library_name String Required Display name of the branch (e.g., Central Library).

2. data/books.csv

Field Name Type Constraint Description
book_id String Primary Key, Unique Unique catalog ID for the book (e.g., B101).
title String Required Book title.
author String Required Author's full name.
isbn String Standard Format International Standard Book Number.
publication_year Integer 1000 ≤ Year ≤ Current Four-digit publication year.
library_id String Foreign Key References libraries.csv branch ID.
