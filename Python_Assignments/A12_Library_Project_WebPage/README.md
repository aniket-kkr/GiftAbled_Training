# A12 - Library Project Webpage

A responsive webpage explaining the Library Management System project, its architecture, CSV data persistence, and usage.

## Files
- `index.html`: Web page detailing project features, system architecture, CSV schemas, and an interactive CLI simulator.
- `main.py`: FastAPI server to serve the webpage.
- `requirements.txt`: Python dependencies (`fastapi`, `uvicorn[standard]`).

## Run
Install requirements and start the FastAPI web server:

```bash
pip install -r requirements.txt
python main.py
```

Then open your browser at:
`http://127.0.0.1:8000`
